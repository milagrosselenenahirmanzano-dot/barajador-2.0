## Descripción del proyecto:

Este proyecto consiste en una máquina repartidora y mezcladora automática de cartas. La idea principal es automatizar una tarea que normalmente se hace de forma manual: mezclar y repartir cartas entre varios jugadores.

El producto busca que el reparto sea más rápido, cómodo y parejo. Para lograrlo, el sistema utiliza una estructura física, motores, rodillos, botones de control y una placa Arduino encargada de controlar el funcionamiento.

## Herramientas utilizadas:

- HTML5
- CSS3
- JavaScript
- Arduino
- Diseño 3D
- Cortadora láser
- Componentes electrónicos
